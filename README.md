# Real-Time Dispatching Dataset

本資料集用於論文：

**「用於智慧製造即時派工之集中式多代理人系統的深度強化學習演算法」**

資料集描述具有多種配方、平行機群、交期限制與改機需求的生產排程環境。

## Dataset Overview

| File           | Description | Records |
| -------------- | ----------- | ------: |
| `schedule.csv` | 待排程子批資料     |   1,000 |
| `mach.csv`     | 機群狀態資料      |     150 |

資料集共包含 25 種配方（Recipe）。

## schedule.csv

`schedule.csv` 記錄所有等待派工的子批資訊。

| Column       | Description         |
| ------------ | ------------------- |
| `TT_LOT_NO`  | 母批編號。一個母批可被拆分為多個子批。 |
| `SCHEDULE`   | 子批編號，也是每筆待排程工作的識別碼。 |
| `DUE_DATE`   | 子批交期，表示子批應完成的期限。    |
| `RECIPENAME` | 加工配方，表示子批所需的製程條件。   |
| `PROD_TIME`  | 加工時間，單位為小時。         |

## mach.csv

`mach.csv` 記錄各機群在排程開始時的狀態。

| Column         | Description                                       |
| -------------- | ------------------------------------------------- |
| `EQP_GROUP_ID` | 機群編號，也是每個機群的識別碼。                                  |
| `m_count`      | 機群內的平行機台數量。數量越多，可同時處理的子批越多。                       |
| `NEW_RECIPE`   | 機群目前的加工配方。若下一個子批配方不同，則需要改機。                       |
| `Arrive`       | 機群最快可用時間，單位為小時。例如 `Arrive = 2` 表示機群在排程開始 2 小時後可用。 |

## Scheduling Rules

* 每個子批需分配至一個機群進行加工。
* 子批的實際加工能力會受到機群內機台數量影響。
* 若子批配方與機群目前配方不同，需加入改機時間。
* 若子批完成時間超過 `DUE_DATE`，則產生延遲。
